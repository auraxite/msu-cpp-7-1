# Сжатие графа

Сериализация и десериализация неориентированного взвешенного графа из TSV в компактный бинарный формат.

## Как работает

Всё кодируется одним 64-битным range coder'ом (арифметическое кодирование). Сторонние библиотеки не используются.

1. **Идентификаторы вершин.** Уникальные id сортируются, и записываются разности между соседними (код Райса). Дальше вершина обозначается номером в этом списке.
2. **Степени.** Для каждой вершины записываются её степень (гамма-код Элиаса с адаптивными битами) и флаг петли с её весом.
3. **Рёбра.** Вершины обходятся по порядку, и для каждой кодируются соседи с большим номером. Вероятность соседа пропорциональна его ещё не использованной степени. Из-за степенного распределения на ребро к «популярной» вершине уходит меньше бит. Суммы степеней хранятся в дереве Фенвика, поэтому выбор соседа занимает O(log N).
4. **Веса.** Веса распределены равномерно и не сжимаются, поэтому записываются как есть, по 8 бит.
